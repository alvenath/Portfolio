# ⚡ Maxiemillian // Systems Architect & Creative Technologist

A minimalist developer portfolio with warm espresso & cognac palettes, fluid micro-interactions, responsive 3D card tilt, constellation canvas background, interactive developer CLI terminal, and project deep-dive case studies.

---

## 🌟 Key Features

1. **Warm Artisan Palette**: Deep espresso and dark walnut with warm amber, cognac, and linen highlights.
2. **Interactive Ambient Canvas**: Subtle golden amber stardust particle mesh that reacts to cursor proximity.
3. **Custom Interactive Cursor**: Smooth trailing ring cursor with hover states.
4. **Dynamic Typewriter**: Animated role rotator with backspacing and clean border cursor.
5. **Interactive 3D Hero Card**: 3D perspective tilt with real-time gradient glare reflection following mouse coordinates.
6. **Interactive Developer CLI Terminal**:
   - Runnable commands: `help`, `skills`, `projects`, `about`, `contact`, `quote`, `clear`.
   - Quick-execute command chips.
7. **Skills Matrix with Live Filter Tabs**: Dynamic category filtering (Frontend, Backend, Cloud, Databases).
8. **Deep Dive Project Modals**: Complete modal popups with throughput/latency metrics and architectural breakdowns.
9. **Synthesized UI Audio Effects**: Procedural Web Audio API sound effects with mute toggle.
10. **Dark / Light Mode**: Instant toggle with smooth color palette transitions.
